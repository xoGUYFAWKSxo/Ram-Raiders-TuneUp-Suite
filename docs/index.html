GALACTIC TUNE-UP
Windows 10 and 11

A Windows maintenance tool that shows you what it measured and lets you undo what it changed.

Galactic Tune-Up is a C# / WPF desktop app with a background Windows service that does the work needing administrator rights. It frees standby memory, names the drivers behind DPC latency spikes, cleans junk files with community winapp2 rules, repairs broken registry entries after backing them up, and applies Windows tweaks you can revert.

Features

What it does

Standby memory purge

Empties the Windows standby list on request. The optional auto-purge checks every 5 seconds and acts only when free memory is below 10% of RAM and standby holds at least as much, at most once a minute. The log shows the amount actually freed.

Driver DPC latency monitor

Shows each CPU core's share of time spent on driver DPCs and interrupts, and runs a kernel trace that names each driver and its longest single run in microseconds, with advice for slow ones. Results can be saved as a text report or CSV.

ProBalance and Game Booster

ProBalance lowers the priority of background programs that hog the CPU and restores it afterwards. Game Booster raises the running game to High priority and, on hybrid CPUs with at least three performance cores, keeps it on those cores.

Rule-based cleaner

Scans with community winapp2 rules and lists every file before anything is deleted. Also finds exact duplicate files (SHA-256, keeps one copy) and empty folders. Event logs, the CBS log, registry hives and the component store are never cleaned.

Registry Guard

Finds uninstall entries, startup entries and COM registrations that point to missing files. Each key is backed up to a timestamped file before it is removed.

Component repair

Reads the Windows CBS log for corruption, runs DISM RestoreHealth and SFC, and reports what they actually returned.

Windows tweaks and MSI mode

30+ registry tweaks for gaming, networking, Explorer and the context menu, plus an MSI interrupt mode switch for devices still on legacy interrupts. Original values are recorded first, and uninstalling restores them.

Storage tools

Moves a large folder, such as a game, to another drive and leaves an NTFS symbolic link behind, so programs keep finding it without a reinstall.

Plain facts

What it doesn't do

Performance

  • It doesn't promise more FPS. Freeing standby memory helps only when a PC is actually short on free memory. Priority changes help only when background programs compete for the CPU.
  • It doesn't fix drivers. The DPC monitor tells you which driver is slow; updating, rolling back or removing that driver is up to you.
  • MSI mode rarely helps on current hardware. Most modern devices already use it.
  • It shows no made-up numbers. Every figure in the app is measured on your PC; nothing is estimated or scored.

Privacy and safety

  • No telemetry, accounts or ads. The only time it goes online is when you click to update the cleaner rules, which downloads winapp2.ini from GitHub.
  • It doesn't delete without a backup. Registry entries are backed up first, and system changes are recorded so uninstalling undoes them.
  • It isn't code-signed. Windows SmartScreen will warn that the publisher is unknown. Each installer ships with a SHA-256 checksum so you can check your copy.
  • It's tested on one PC so far. Version 1.0.0 has been installed, upgraded and uninstalled on the developer's PC, but not yet tested on a clean one.
